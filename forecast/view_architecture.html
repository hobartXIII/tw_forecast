🌤️ 台灣天氣預報與自動化通報系統

系統架構圖與核心資料流程 (System Architecture & Data Pipeline Visualizer)

⚡ 流程一：Python 打 API 取資料存 DB

  • 資料源：中央氣象署 CWA API (F-C0032-001)。
  • 排程執行：GitHub Actions 依自訂 Cron 排程啟動虛擬環境 (亦支援隨時手動觸發)。
  • 清洗與入庫：fetch_and_store.py 透過 Pandas 轉換資料，批量 Upsert 存入雲端 Supabase (weather_forecasts)。
  • 智慧告警：當降雨機率 PoP ≥ 60% 時，發送卡片通知至 Google Chat Webhook。

✨ 流程二：DB 撈取資料轉 JSON 提供前端

  • 資料庫查詢：export_db_to_json.py 執行最佳化 SQL 查詢全台最新時段預報。
  • 標準 JSON 產出：產出 data/weather_latest.json，包含經緯度、溫度、降雨率與週趨勢。
  • 前端解耦消費：
    • Streamlit 儀表板：讀取 JSON 渲染折線圖與 Folium 台灣地圖。
    • 輕量 Web 網頁：透過原生 fetch() 渲染即時氣象卡片，零後端負擔。
