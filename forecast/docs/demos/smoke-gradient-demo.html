煙霧的運算都在 GPU 上，JS 量不到它的耗時，所以這版主要看「實際幀率」有沒有掉到設定的上限以下。每個像素要算 5 次多層雜訊，「每幀運算像素」乘上「細緻度層數」大致就是 GPU 的工作量。

煙霧與毛玻璃

煙霧是大面積、柔和的變化，和毛玻璃很搭：卡片後面的色塊會慢慢流過，不像粒子那樣有明顯的點狀移動，所以對內文可讀性的干擾也比較小。

建議試試把渲染解析度切到 0.25x，你會發現畫面幾乎沒差，但運算像素只剩原尺寸的 1/16。這就是煙霧效果最划算的優化方式。

內文可讀性測試

這段文字放在卡片裡，用來檢查煙霧較濃的區域飄過時，深淺色模式下的閱讀感受。如果覺得太搶眼，先調低「濃度」，而不是提高卡片的不透明度，這樣玻璃的通透感才保得住。
